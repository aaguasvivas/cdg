# cdg

An LLVM 3.8 pass that builds a control dependence graph (CDG) for C/C++ programs compiled to LLVM IR.

Built during the 2019 DREU summer research program at the University of Illinois Urbana-Champaign, where these passes powered an automated grading and hint-generation system for large CS courses, improving grading throughput by 10x.

Related passes: [pdg](https://github.com/aaguasvivas/pdg) (program dependence graph) and [debuginfopass](https://github.com/aaguasvivas/debuginfopass) (line and type debug info).
